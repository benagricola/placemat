# Fit Frame Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `board.size(fit=True, margin=)` gives a module fragment a frame that is its placed content plus a margin, with planes bounded to it.

**Architecture:** On a fit board the occupancy has no board box while the decided items go down, then a provisional room (the decided content grown by `place.fit_room`) for the search; after every item and the non-plane copper are placed, the frame is the box round the placed content plus the margin, set as the plan's outline, and the planes that follow the frame are planned then. Anything that needs the frame before it exists is refused when declared.

**Tech Stack:** Python 3.12, pytest (pure synthetic boards; one KiCad stamping test).

**Spec:** `docs/superpowers/specs/2026-09-27-fit-frame-design.md` (approved 2026-09-27)

## Global Constraints

- `fit=True` only with `draw=False` (a fragment's frame); `fit=True, draw=True` raises ValueError.
- `margin` defaults to the board's keep-in (`Board.keep_in`).
- `place.fit_room` is a setting, default 10.0 mm, above zero.
- What counts toward the frame: each placed part's shapes as the occupancy claims them (its envelope per `[place] envelope`), label reservations, tracks, vias and pours. Zones (planes) do not.
- Generic wording in src, skill and migrations; plain ASCII; commits carry no tool or session reference.
- Every placement change runs `fixtures/bench.py`; the tally goes in the commit message.

## Review Focus

1. A fit board whose content sits at negative coordinates (parts pinned west or north of the first part): the frame, the planes and the extent follow it; nothing assumes the frame starts at (0, 0). Test in Task 3.
2. A fit board with nothing decided: the first searched item lands at the origin and the rest round it. Test in Task 2.
3. A plane with an explicit `outline=` on a fit board keeps its outline and is planned as before. Test in Task 3.
4. `board.width`, `board.centre`, an `OnEdge` place and an edge row on a fit board raise a clear error at declaration. Test in Task 1.
5. Run reuse: a second run of an unchanged fit script replays and gives the same frame. Test in Task 3.

import pytest

from placemat.layout import Board
from placemat.values import Edge, Location, OnEdge, Part, PadRef, Pin, X, Y
from tests.fixtures import board_geometry, footprint


def _board(**kw):
    fps = [footprint("U1", 20, 20, w=4, h=2, inst="u1", nets=("A", "B")),
           footprint("C1", 30, 30, w=2, h=1, inst="c1", nets=("A", "GND")),
           footprint("R1", 34, 34, w=2, h=1, inst="r1", nets=("B", "GND"))]
    b = Board(board_geometry(fps, width=60, height=60), edge_margin=0.5)
    b.size(fit=True, draw=False, **kw)
    return b


def test_fit_is_for_a_fragments_frame_only():
    b = Board(board_geometry([footprint("U1", 20, 20, inst="u1")], width=60, height=60))
    with pytest.raises(ValueError, match="fit"):
        b.size(fit=True, draw=True)


def test_what_needs_the_frame_is_refused_on_a_fit_board():
    b = _board()
    for ask in (lambda: b.width, lambda: b.height, lambda: b.centre,
                lambda: b.place(Part("c1"), at=OnEdge(Edge.NORTH)),
                lambda: b.row([Part("c1"), Part("r1")], Edge.SOUTH),
                lambda: b.edge(Edge.NORTH)):
        with pytest.raises(ValueError, match="fit"):
            ask()

- [ ] **Step 3: Implement**

Settings: `place_fit_room: float = 10.0   # a fit frame's provisional room: how far round the decided content a searched item may go`, added to `_ABOVE_ZERO`.

`Board.__init__`: `self._fit = False`, `self._fit_margin = 0.0`, and store width/height as `self._width`, `self._height`, with properties:

```python
    @property
    def width(self) -> float:
        if self._fit:
            raise ValueError("a fit frame has no width until its content is placed: the plan's outline has it")
        return self._width

    @width.setter
    def width(self, v):
        self._width = v
```

(the same for `height`). `Board.size` gains `fit: bool = False, margin: float | None = None` after the existing keywords, and `width`/`height` default to `None`:

```python
        if fit:
            if draw:
                raise ValueError("fit=True sizes a fragment's frame (draw=False); a board's outline is a mechanical fact")
            self._fit, self._fit_margin = True, self.keep_in if margin is None else float(margin)
            self._outline, self._shape, self._cached_outline = None, None, None
            self._cutouts = Cutouts()
            self._chamfer, self._radius = chamfer, radius
            self._sized, self._draw_outline = True, False
            return
```

`Board.centre`, `Board.edge`, `Board.row` (when `edge` is an `Edge`) and `Board.place` (when `at` is an `OnEdge`) start with:

```python
        if self._fit:
            raise ValueError("<what>: a fit frame has no edges until its content is placed")
```

- [ ] **Step 3: Implement**

In `resolve`, after the `Occupancy(...)` is built: `if self._fit: occ.board_box = None` (no edge to judge the decided items by). After `place_ranked(RANK_FIXED, RANK_EDGE)` and the fixed copper:

```python
        if self._fit:
            decided = self._placed_box(occ, plan)
            room = self.settings.place_fit_room
            occ.board_box = (decided.inflate(room) if decided is not None
                             else Box(-room, -room, room, room))
            self._outline = occ.board_box            # the search's fallback hint and pockets read it
```

`_placed_box` unions `occ.items[r].shapes` boxes for every placed owner (`occ.items` minus `occ.pending`), `occ.copper` shapes whose kind is not a zone, and the label reservations (`occ` region shapes whose owner is a label key); returns None when empty. With nothing decided the room is centred on the origin, so the first searched item's fallback hint (`self._outline.center`) is the origin.

```python
from placemat.copper import Zone
from placemat.values import CopperLayer, Net


def _pinned(b):
    b.place(Part("u1"), at=Location(0, 0))
    b.place(Part("c1"), at=Pin(1, X(PadRef(Part("u1"), 1), -3.0), Y(PadRef(Part("u1"), 1))))
    return b


def test_the_frame_is_the_content_plus_the_margin():
    b = _pinned(_board(margin=0.5))
    plan = b.resolve()
    content = b._placed_box(plan.occupancy, plan)
    assert plan.outline == content.inflate(0.5)
    assert plan.outline.left < 0          # c1 sits west of u1: the frame is not at the origin


def test_a_plane_is_inset_from_the_fitted_frame_and_does_not_size_it():
    b = _pinned(_board(margin=0.5))
    b.plane(Net("GND"), layers=(CopperLayer.B,))
    plan = b.resolve()
    (z,) = [c for c in plan.copper if isinstance(c, Zone)]
    xs, ys = [p[0] for p in z.points], [p[1] for p in z.points]
    inset = b.settings.copper_plane_inset
    assert abs(min(xs) - (plan.outline.left + inset)) < 1e-6 and abs(max(ys) - (plan.outline.bottom - inset)) < 1e-6


def test_a_plane_with_its_own_outline_keeps_it():
    b = _pinned(_board())
    pts = [Location(-1, -1), Location(1, -1), Location(1, 1), Location(-1, 1)]
    b.plane(Net("GND"), layers=(CopperLayer.B,), outline=pts)
    (z,) = [c for c in b.resolve().copper if isinstance(c, Zone)]
    assert set(z.points) == {(-1, -1), (1, -1), (1, 1), (-1, 1)}


def test_an_unchanged_fit_script_replays_to_the_same_frame():
    first = _pinned(_board()).resolve()
    again = _pinned(_board()).resolve(reuse=first.reuse)
    assert again.reuse["reused"] > 0 and again.outline == first.outline
```

- [ ] **Step 3: Implement**

`copper.board_zone_outline(width, height, inset, chamfer=0.0, origin=(0.0, 0.0))` adds `origin` to every point.

`Board.plane`: when `self._fit` and `outline is None`, the intent's plan reads the fitted frame:

```python
            elif self._fit:
                f = ctx.plan.outline
                pts = board_zone_outline(f.width, f.height, inset, ch, origin=(f.left, f.top))
```

and the intent is recorded in `self._fit_planes` (its key) so `resolve` holds it back.

In `resolve`: take the `_fit_planes` intents out of `fixed_copper` and `other_copper`; after `self._plan_copper(occ, ctx, other_copper, plan, progress)`:

```python
        if self._fit:
            content = self._placed_box(occ, plan)
            frame = (content or Box(0.0, 0.0, 0.0, 0.0)).inflate(self._fit_margin)
            plan.outline = self._outline = occ.board_box = frame
            self._plan_copper(occ, ctx, [c for c in self._copper if c.key in self._fit_planes], plan, progress)
```

before `self._check_keepouts(plan)` and `plan.rudy = ...`. The replay path goes through the same code, so the frame is recomputed from the replayed placements.
