# Explore Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `placemat run --explore SECONDS` tries seeded variants of the focused items' choices in parallel; `--accept` records the best as anchor-relative decisions in a lock file a run then applies deterministically; `placemat freeze` moves lock entries into the script.

**Architecture:** An `Explore` value (seed, focus keys, slack, swap) passed to `Board.resolve()` changes two things for focused items only: the order (adjacent swaps) and the pick among scan candidates (a rank-weighted draw within the slack). A new `explorer.py` runs seeds in worker processes until a deadline, scores each plan and returns the best; its decisions for the focused items become lock entries (anchor pad, offset and rotation in the anchor's frame, face, declaration digest) that `resolve()` tries first at each locked item's turn. `freeze` edits the item's `place()` call and accepts the edit only if the frozen script resolves to the locked placements.

**Tech Stack:** Python standard library (`multiprocessing`, `random`, `json`, `ast`); LibCST only if chosen for freeze, as an optional extra; the native module is used when present, not required.

**Spec:** `docs/superpowers/specs/2026-09-25-explore-design.md`

## Global Constraints

- Seed 0 is today's placement exactly: suite and bench unchanged with no `--explore`.
- Deterministic per seed: `random.Random` seeded from (seed, item key); no global RNG.
- Zero new runtime dependencies. Generic wording in src, skill and migrations; plain ASCII; no attribution lines.
- Every placement-affecting commit carries the bench tally.
