# Explore Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `placemat run --explore SECONDS` tries seeded variants of the focused items' choices in parallel and keeps the best-scoring board.

**Architecture:** An `Explore` value (seed, focus keys, slack, swap) passed to `Board.resolve()` changes two things for focused items only: the order (adjacent swaps) and the pick among scan candidates (a rank-weighted draw within the slack). A new `explorer.py` runs seeds in worker processes until a deadline, scores each plan, and returns the best seed; the runner then resolves that seed and carries on as a run does.

**Tech Stack:** Python standard library (`multiprocessing`, `random`); the native module is used when present, not required.

**Spec:** `docs/superpowers/specs/2026-09-25-explore-design.md`

## Global Constraints

- Seed 0 is today's placement exactly: suite and bench unchanged with no `--explore`.
- Deterministic per seed: `random.Random` seeded from (seed, item key); no global RNG.
- Zero new runtime dependencies. Generic wording in src, skill and migrations; plain ASCII; no attribution lines.
- Every placement-affecting commit carries the bench tally.

### Task 2: The draw in the scan

**Files:** `src/placemat/placer.py` (`scan(..., pick=None)`: when given, called with the legal candidates sorted by `(score, distance, rotation)` and returns one; default the first, as now), tests `tests/test_explore_pick.py`.

### Task 3: Explore in `Board.resolve()`

**Files:** `src/placemat/layout.py` (`resolve(..., explore=None)`; ranked order perturbed by adjacent swaps among focused items; `_settle` passes a `pick` for focused items; the seed joins a focused step's reuse key), `src/placemat/reuse.py` (step key takes an optional extra), tests `tests/test_explore_resolve.py`.

- [ ] Failing tests: `explore=Explore(seed=0, ...)` gives the same plan as `explore=None`; two resolves with seed 7 give identical steps; with seed 7 an unfocused item's placement equals seed 0's; across 32 seeds a focused item takes more than one placement; a variant's steps before the first focused item are reported as reused.
- [ ] Implement; suite; bench (must be same 32 x3); commit with tally.

- [ ] Failing tests: `score` orders placed, then findings, then cost; `explore` with `seeds=[0, 1, 2]` and jobs 1 and 2 returns the same best seed; seed 0 is always in the result; the deadline is honoured within one variant's time.
