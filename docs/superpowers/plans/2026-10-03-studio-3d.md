# Studio 3D, phase 1: plan

Spec: `docs/superpowers/specs/2026-10-03-studio-3d-design.md` (approved). This plan is phase 1 only: placed models, live.
Branch `studio-3d`. Each unit is built test first; a unit is done when its tests pass and it is committed.

## Where the code goes

3D lives in its own modules and files. The shared files it touches are listed at the end and kept to the smallest edit.

| Module | Job |
| --- | --- |
| `models.py` (existing) | `resolve_model`: a model entry's text to a file, an embedded name or a reason; KiCad path variables; `.wrl` to `.step`; content ids. `reanchor` stays. `describe._model_path` becomes a caller. |
| `model_place.py` | The placement chain as one affine map, composed in Python: model frame to scene frame; the planes constants; the stackup thickness. Pure. |
| `model_mesh.py` | The `.pmm` mesh file (write, read), GLB reading, the model frame rewrite, decimation by vertex clustering. Pure, standard library only. |
| `model_vrml.py` | VRML 2 reader (own parser, 0.1 inch unit). |
| `model_cache.py` | The shared user cache: paths, atomic writes, failure records, version prefix, the LRU bound. |
| `model_convert.py` | The converter: batches through `kicad-cli pcb export glb`, the self-test, the VRML path; runs as its own process (JSON lines on stdin and stdout, as `WorkerProcess`). |
| `model_plan.py` | What the plan JSON carries about models: per member `models`, the plan's `stackup` and `models` table. |
| `studio_3d.py` | The studio side: owns the converter process, the queue, the model table, SSE events, the GET and POST handlers' bodies. |
| `studio_3d.js`, `vendor/three/` | The viewer (loaded by `import()` when 3D is first opened) and three.js with its licence. |

## Units, in order

1. **Resolution.** `models.resolve_model(text, project_dir, ...)` returns a record `{state, path, name, text, embedded, why}` with
   state `ok`, `none`, `missing`, `hidden`, `vrml` (a `.wrl` with no STEP). Cases: `kicad-embed://`, absolute, `${KIPRJMOD}` with the
   re-anchoring `reanchor` applies, other `${NAME}` (environment, KiCad's variables, the standard model folders, the setting
   `studio_3d_model_dirs`), relative to the project, `.wrl` to a STEP beside it. Content id: 32 hex of SHA-256, remembered by
   (path, mtime, size); `e-` plus the embedded file's checksum. `read._models` gains the hide flag and opacity.
2. **Placement.** `model_place.matrix(...)` composes: model entry (offset, rotation, scale), the footprint's pose as generated, the
   plan's transform to the placed pose (the same one `_drawn_at` builds), the face, and the stackup planes, into one 4x4 from the
   model frame to the scene frame (x = board x, y = up, z = board y). Tests: hand-computed corners of an asymmetric prism, front,
   back, flipped by the plan or not.
3. **Mesh and cache.** `.pmm` round trip; vertex clustering that ends under the cap and keeps the box; cache atomic write, LRU
   bound that spares files in use, version prefix removal, failure records.
4. **VRML.** The reader, tested on a small written file (a box with a colour, unit 0.1 inch).
5. **Converter.** GLB reader, the model frame rewrite, batches, self-test on the planes, a bad model failing alone, `kicad-cli`
   absent as one message. Tests that need `kicad-cli` are gated on it.
6. **Plan document.** `item_json`/`plan_json` take an optional model context and add `models` per member, `stackup` and `models`
   to the plan; `VERSION` 2; an older plan still draws. The end-to-end check: write the board of a plan, export it with
   `kicad-cli`, and compare every vertex of each part with the matrix applied to the cached mesh within 1 um, and the pads of the
   same footprints.
7. **Studio side.** Settings; the manager and its events; `GET /3d/models`, `/3d/model/<id>.pmm`, `/3d/viewer.js`,
   `/vendor/three/<file>`; `POST /3d/retry`; the `models` table in `hello`.
8. **Viewer and page.** three.js vendored; the viewer: body from the outline with cutouts and drills, parts as instanced meshes per
   (model, material) at their matrices, plates for parts with no model, orbit/pan/zoom, fit, top/bottom/iso, touch, selection
   parity, theme; the 2D | 3D switch; `showSteps(k)`, live arrival of parts, the models legend. Page tests for the pure parts
   (visible set at step k); a browser run for the rest.
9. **Measure and document.** Frame rate on the 258-part board in headless Chrome; the resolve cost on the large fixture;
   `SKILL.md` (short), `api.md` ("Studio"), migration under Unreleased.

## What is measured, not assumed

- The placement against `kicad-cli` (unit 6), to 1 um.
- The planes (front `T - 0.005`, back `-0.085`) by the converter's self-test at start-up.
- The resolve cost of model resolution on the 258-part board.
- The frame rate in a browser, with the number of draw calls and triangles.
